# LIMS 业务数据清理指南

> 用于按创建时间删除测试/历史业务数据，**不影响**基础数据（客户、供应商、设备、检测标准、用户等）。

## 一、连接数据库

```bash
# 方式1：本地通过 SSH
sshpass -p 'xx198910170014Z' ssh root@8.130.182.148 \
  "mysql -u root -plims_mysql_2024 -P 3308 -h 127.0.0.1 lims"

# 方式2：服务器上直接执行
mysql -u root -plims_mysql_2024 -P 3308 -h 127.0.0.1 lims
```

## 二、删除顺序（必须从下游到上游）

> [!CAUTION]
> **必须按以下顺序执行**，否则会因外键约束报错。每条 SQL 中的日期 `'YYYY-MM-DD'` 替换为你想要的截止日期。

```sql
-- ⚠️ 先关闭外键检查
SET FOREIGN_KEY_CHECKS=0;

-- 1️⃣ 客户报告
DELETE FROM biz_client_report WHERE createdAt < 'YYYY-MM-DD';

-- 2️⃣ 任务报告
DELETE FROM biz_test_report WHERE createdAt < 'YYYY-MM-DD';

-- 3️⃣ 检测任务 + 检测数据
DELETE FROM biz_test_data WHERE taskId IN (SELECT id FROM biz_test_task WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM biz_test_task WHERE createdAt < 'YYYY-MM-DD';

-- 4️⃣ 样品检测项 + 样品加工 + 样品领用 + 样品
DELETE FROM biz_sample_test_item WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_sample_processing WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_sample_requisition WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_sample WHERE createdAt < 'YYYY-MM-DD';

-- 5️⃣ 委托单项目 + 委托单
DELETE FROM biz_entrustment_project WHERE entrustmentId IN (SELECT id FROM biz_entrustment WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM biz_entrustment WHERE createdAt < 'YYYY-MM-DD';

-- 6️⃣ 合同明细 + 合同
DELETE FROM biz_contract_item WHERE contractId IN (SELECT id FROM biz_contract WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM biz_contract WHERE createdAt < 'YYYY-MM-DD';

-- 7️⃣ 报价审批 + 报价明细 + 报价单
DELETE FROM biz_quotation_approval WHERE quotationId IN (SELECT id FROM biz_quotation WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM biz_quotation_item WHERE quotationId IN (SELECT id FROM biz_quotation WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM biz_quotation WHERE createdAt < 'YYYY-MM-DD';

-- 8️⃣ 业务咨询评估 + 跟进 + 咨询
DELETE FROM consultation_sample_assessment WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_consultation_assessment WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_consultation_followup WHERE createdAt < 'YYYY-MM-DD';
DELETE FROM biz_consultation WHERE createdAt < 'YYYY-MM-DD';

-- 9️⃣ 审批记录 + 审批实例
DELETE FROM sys_approval_record WHERE instanceId IN (SELECT id FROM sys_approval_instance WHERE createdAt < 'YYYY-MM-DD');
DELETE FROM sys_approval_instance WHERE createdAt < 'YYYY-MM-DD';

-- ✅ 恢复外键检查
SET FOREIGN_KEY_CHECKS=1;
```

## 三、一键脚本（替换日期即可）

```bash

CUTOFF="2026-02-20"

sshpass -p 'xx198910170014Z' ssh root@8.130.182.148 "mysql -u root -plims_mysql_2024 -P 3308 -h 127.0.0.1 lims -e \"
SET FOREIGN_KEY_CHECKS=0;
DELETE FROM biz_client_report WHERE createdAt < '$CUTOFF';
DELETE FROM biz_test_report WHERE createdAt < '$CUTOFF';

DELETE FROM biz_test_task WHERE createdAt < '$CUTOFF';
DELETE FROM biz_sample_test_item WHERE createdAt < '$CUTOFF';
DELETE FROM biz_sample_processing WHERE createdAt < '$CUTOFF';
DELETE FROM biz_sample_requisition WHERE createdAt < '$CUTOFF';
DELETE FROM biz_sample WHERE createdAt < '$CUTOFF';
DELETE FROM biz_entrustment_project WHERE entrustmentId IN (SELECT id FROM biz_entrustment WHERE createdAt < '$CUTOFF');
DELETE FROM biz_entrustment WHERE createdAt < '$CUTOFF';
DELETE FROM biz_contract_item WHERE contractId IN (SELECT id FROM biz_contract WHERE createdAt < '$CUTOFF');
DELETE FROM biz_contract WHERE createdAt < '$CUTOFF';
DELETE FROM biz_quotation_approval WHERE quotationId IN (SELECT id FROM biz_quotation WHERE createdAt < '$CUTOFF');
DELETE FROM biz_quotation_item WHERE quotationId IN (SELECT id FROM biz_quotation WHERE createdAt < '$CUTOFF');
DELETE FROM biz_quotation WHERE createdAt < '$CUTOFF';
DELETE FROM consultation_sample_assessment WHERE createdAt < '$CUTOFF';
DELETE FROM biz_consultation_assessment WHERE createdAt < '$CUTOFF';
DELETE FROM biz_consultation_followup WHERE createdAt < '$CUTOFF';
DELETE FROM biz_consultation WHERE createdAt < '$CUTOFF';
DELETE FROM sys_approval_record WHERE instanceId IN (SELECT id FROM sys_approval_instance WHERE createdAt < '$CUTOFF');
DELETE FROM sys_approval_instance WHERE createdAt < '$CUTOFF';
SET FOREIGN_KEY_CHECKS=1;
SELECT 'cleanup done' as result;
\""
```

## 四、不会被删除的表（基础数据）

| 表名 | 说明 |
|------|------|
| `biz_client` | 业务单位/客户 |
| `biz_supplier` / `biz_supplier_category` | 供应商 |
| `biz_device` / `biz_device_*` | 设备台账 |
| `biz_consumable` / `biz_consumable_*` | 易耗品 |
| `biz_test_template` | 检测项目模板 |
| `biz_inspection_standard` / `biz_inspection_item` | 检测标准 |
| `biz_report_template` | 报告模板 |
| `sys_user` / `sys_role` / `sys_permission` | 用户/角色/权限 |
| `sys_approval_flow` | 审批流程配置 |
